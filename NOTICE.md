# PacketLab attribution & notices

PaketLab is a virtual Android networking lab developed under the Veyra project.

## TopoLab — original foundation

The original TopoLab project is authored by **Vansh Bhardwaj**, accessible at
https://github.com/vansh231205/TopoLab.

Parts of PacketLab are based on the original TopoLab graph model, topology renderer, route calculations, graph algorithms, device templates, and the original interactive network-workspace concept. The full, preserved public upstream snapshot is included in `upstream/TopoLab/` with its comments, original README and supporting files. Original contributions are not silently renamed or presented as uniquely written for PacketLab.

At the time this repository was prepared, the original public TopoLab repository was not accompanied by an explicit standalone license file. **No Apache, MIT, GPL or other license is asserted over the original author's contributions here.** The original rights remain with their rightsholders. Public availability alone does not grant a blanket downstream license. If a license/permission instrument is available, maintainers should add the written terms to this notice.

## PacketLab extension

New PacketLab-specific functionality includes Android wrapping, design layers, virtual device profiles, security/firewall simulations, Learning Mode, new v0.6 packet engine, packet console, tests and project website.

## Virtual security experiments

All described vulnerability, spoofing, filter-evasion, traffic flood and device state experiments are synthetic/local simulation events. They do not send attack packets over real interfaces.
