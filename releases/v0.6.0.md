**Build a Network · Packet Console · Network Master · Firewall & Logs** 💜

## Highlights

- **Blank canvas** with no devices preinstalled. Add hardware and cables yourself with preserved original TopoLab topology tools.
- **One simulated packet delivery path** with virtual routing, firewall checks, per-device logging, explicit effects and ordinary packets that don't unexpectedly power devices off.
- **Expandable packet panel**, tap-to-pick source/destination, custom protocol/port/payload/count, spoof/evasion model flags and long virtual uploads/downloads.
- **Learning & Network Master** with explicit save/discard, local .pklab drafts, file import, new tasks, nine exercise presets and percentage scoring. Terminal-first editing in Master; Easy Edit and Edit More remain in Standard.
- **Firewall configuration** with local software host filtering vs. dedicated network security checkpoints on a virtual path, rule order, default policy and model-based limits.
- **Always-on simulation clock**, user pause/resume; no arbitrary background traffic by default.
- **Responsive UI** in portrait, landscape and desktop-size preview.
- **Original TopoLab foundation is retained.** Credits and copyright provenance are in the app footer, website footer, README and preserved upstream snapshot.

## Important limitations

Security events (virtual worms, spoofed packets, flood, outages and virtual filter evasion) are synthetic and local. They **do not generate or send real malicious network traffic**.

Only explicitly selected virtual scenario effects change devices to offline status. A normal packet should never make a device disappear from the graph.

The dedicated firewall is a *virtual checkpoint*: it filters modeled packets only when their actual graph route traverses it. Switches are not default firewalls, and WAN traffic requires a real configuration **in the virtual network**.
