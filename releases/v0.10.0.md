# PacketLab v0.10.0 — Net@Lab V2

The Net@Lab offline handbook has been rebuilt as a full interactive learning environment in the existing PacketLab Android app.

## Net@Lab V2

- Completely redesigned OLED chapter library with polished VeyraLabs brand, 15 clearly structured knowledge categories, full-text search, reading history and saved bookmarks.
- All 62 existing German technical chapters retained, now presented with readable typography, clear section hierarchy, contextual learning goals, command examples, memorization notes and common failure patterns.
- A topic-specific read-only miniature network accompanies **every chapter**. Interactive PC, switch, router, server, firewall, access point and smartphone examples show realistic IPv4/IPv6 profiles, subnet masks, gateways, MAC addresses, network interfaces, static routes, virtual services, firewall rules and sample logs.
- Teaching models for IPv4 subnetting, IPv6/Neighbor Discovery, ARP, VLAN switching, DHCP, DNS, firewall/ACL, NAT/PAT, WLAN, HTTP/TLS, Linux, Windows and Cisco IOS.
- Dedicated "packet path" explorer with highlighted hops, multiple explanatory steps and layer labels.
- Switch from "Beispielnetz" to "Mein Lab" to view the **currently open virtual PacketLab network**, entirely read-only, without overwriting any saved world.
- Responsive mobile layouts including a large, readable chapter view and accessible device controls. No native Android select popups inside the handbook.
- A dedicated per-topic visual reference card with concrete calculations, data-flow definitions or protocol vocabulary.
- Compatible with existing learning progress and bookmarks saved by Net@Lab V1.

## Technical boundaries

The illustrated networks are educational deterministic simulations. The read-only "Mein Lab" view reads PacketLab model state, not the actual phone's WLAN or hardware. Net@Lab does not execute host commands, make external network requests or send real packets. It does not pretend to implement Cisco IOS hardware or full OS emulation.

The existing PacketLab features, world formats, lessons, device editors, firewall controls and Android package ID are preserved.
