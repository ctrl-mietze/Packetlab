# PacketLab 0.11.0 — Network Training Catalog, Quick Edit and Net@Lab

The new version fixes the five-button navigation overflow in Network Lab Training and replaces the old empty-canvas menu with a compact, deliberate touch gesture.

## Network Lab Training

- Stable four-button bottom navigation: Network, Devices, Inspector and Analysis. The extra "Aufgaben" tab no longer wraps to a second row.
- The training library button is now "Training öffnen", not "Neues Lab". The catalog contains one playable virtual network exercise for each Net@Lab article.
- Each lesson has a title, short summary, dedicated preview with more context, a selectable difficulty, and a deliberate Start button.
- Four difficulty levels. Einfach creates one objective and exposes three mini tips per objective. Normal has two objectives and two tips. Fortgeschritten has three objectives and one tip. Experte has four objectives and no tips.
- Starting a training initializes a private simulated star network with deliberately incorrect or incomplete device settings and creates an ordinary .worklab challenge.
- The top book button opens the active objectives, progress and difficulty-adjusted mini tips. The actual Net@Lab encyclopedia remains accessible from a separate "Net@Lab-Handbuch öffnen" action in that taskbook. Training exercises never appear on encyclopedia pages.
- Previously saved and imported .worklab challenges, the editable Training Builder, project libraries and the existing .pklab file format remain available.
- Goals use the existing real model evaluator: IPv4, IPv6, masks, gateways, DNS, VLAN, virtual cable connection, online status, host firewall and server service flags. Initial goal values are intentionally unresolved.

## Net@Lab expansion

- 20 Fundamentals chapters and 20 IPv4 chapters, now 90 articles in total.
- New detailed material covers packet encapsulation, OSI, LAN/WAN/VPN, topology, MAC, TCP/UDP, systematic diagnostics and IPv4 calculations.
- IPv4 includes fully worked examples for /20, /22, /25–/32, VLSM, binary AND, gateway mismatch and DHCP subnet design.
- The earlier interactive read-only device demos, per-chapter packet flow, search, bookmarks and reading progress are preserved.

## Quick Edit gesture

- Available **only in free Network Lab**. The old "CANVAS" context menu is disabled on empty canvas space in all lab modes.
- Compact quick menu with clients, switching/WLAN, routing/security, server infrastructure, Repair Network, Smart Fix and Building Agent.
- A long press opens the menu without arming any item. The user must move the finger at least 15 pixels, dwell on a category for 315 ms, then move to a submenu choice and dwell for 245 ms. Releasing executes only a fully armed item under the finger; releasing without movement or dwelling does nothing.
- No unintended canvas panning, device dragging or placement while the gesture menu is open.
- Existing device and cable context menus are preserved.

## Validation

- Mobile Chromium end-to-end workflow suite, including all 90 handbook chapters, lesson catalog, chapter preview, difficulty, taskbook, isolated example world, modal use, navigation geometry and swipe-to-select Quick Edit.
- Original 12 core model tests and 18 network engine tests.
- Android Gradle debug build, unchanged package ID and existing debug signing certificate.

## Boundaries

All labs are virtual. These scenarios do not run commands on the host OS, scan a physical network or perform attacks. The existing Building Agent still requests explicit permission when used.
