# PacketLab 0.8.0 — Unified OLED Studio & Virtual OS Console

A major **design/architecture update** to the existing Android network simulator. Package ID `ctrl.mietze.veyrapacketlab` remains unchanged; versionCode is 9.

## Device Studio rebuilt

- One isolated, accessible mobile device sheet with consistent OLED rows, one icon per action, no floating purple placeholders, no doubled legacy decorator markup.
- Unified summary of device, IPv4, subnet, MAC, OS and online state.
- Clear navigation groups: Configuration, Network & Hardware, Diagnostics & Actions.
- Keeps Easy Edit, Edit More, terminal, basic firewall, advanced Firewall Studio PRO, hardware modules, server services, Android/iOS phone editor, logs, inspector, move mode, power and deletion.
- A fallback redirects remaining legacy quick-edit sheet entry points to the new renderer.

## Stateful virtual OS environment

- Separate simulated Linux/OpenWrt, Windows, Android, iOS and Cisco IOS profiles.
- Per-device virtual filesystem: folders, working directory, bounded files, copy/move/delete, output and process listing.
- Virtual services and Android settings/packages update model data, never the host OS.
- Virtual Cisco IOS `show version`, `show running-config`, `show ip route`, `configure terminal`, `interface`, `ip address` and `copy running-config startup-config` integration.
- New terminal UI with per-OS prompt, quick commands, command history and copyable output.
- Files for each OS profile are kept separately when switching between the virtual OS families.
- Virtual file and service changes are saved in `.pklab` alongside existing device states.

## Visual system

- Consistent true-dark canvas, restrained purple accents, grouped settings, low-contrast neutral borders, larger tap targets and simpler top, bottom and package UI.
- No excessive animations, gradients, glass or visual decoration.
- The original simulation engine, topology generator, firewall policy checks, cable media, traffic simulation, learning mode and project persistence remain operational.

## Test scope

- 12 baseline core tests + 18 v0.6 simulation tests passed.
- New headless mobile Chromium tests exercise device menu structure and action wiring, Linux/Windows/Android/iOS/Cisco virtual terminals and .pklab serialization.
- Android Gradle debug APK built successfully.

**Scope / limitations:** This is an educational model, not an emulation of physical Cisco hardware or complete Windows/Linux/Android operating systems. No host command execution, real root, external sockets or real cyberattacks. APK size is based on genuine implementation content, not padded to an arbitrary target.
