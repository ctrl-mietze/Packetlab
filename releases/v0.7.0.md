# PacketLab 0.7.0 — Mobile Network Studio

**Update:** Android 10+, package `ctrl.mietze.veyrapacketlab`, versionCode 7. Das bestehende .pklab-v3-Format bleibt erhalten. Das TopoLab-/v0.6-Projekt und sämtliche bisherigen Panels, Konfigurationsoptionen und Netzwerkfunktionen bleiben bestehen.

## Neu

- **Touch-first Netzwerkeditor:** Geräte werden erst beim bewussten Tippen platziert; Wischen über Geräte bewegt die Arbeitsfläche, statt Geräte versehentlich zu verschieben. Verschieben ist ausdrücklich im Gerätemenü aktivierbar, Serienplatzierung optional. Lange Berührung weniger empfindlich.
- **Paketkonsole:** Sofort-Senden direkt im eingeklappten Zustand, mehrfaches Tippen möglich. Play/Stop rechts oben ohne permanent eingeblendete Zeit im Hauptbildschirm.
- **Device Studio:** Gerätespezifische Hardwaremodule, virtuelle Serverdienste, Android/iOS-Smartphone-Konfiguration und optionaler Crazy Mode mit modelliertem Android-Root-/Repeater-Profil.
- **Firewall Studio PRO:** Source-/Destination-IP und CIDR, Portbereiche, Protokolle, LAN/WAN, Reihenfolge, Default-Policy, Inspection, Anti-Spoofing, Rate- und Burst-Limits.
- **IPv4/Subnetting:** Masken werden auf zusammenhängende Bits geprüft; Gateway/Subnetz-Kohärenz sowie modulabhängige Übertragungen werden in virtuellen Paketentscheidungen berücksichtigt. Im Guide ist ein IPv4-Subnetzrechner integriert.
- **Inspector / Analyse:** Inspector zeigt Geräte, Konfiguration, Status, Logs und Fehler; Analyse konzentriert sich auf Diagnosen, Statistiken und konkrete Verbesserungsvorschläge.
- **PDU Inspector und Event Explorer:** Hop-für-Hop-Modell, OSI-Einordnung und durchsuchbare lokale Netzwerkereignisse. Keine echten Netzwerk-Sniffs.
- **Vorlagen und Learning Mode:** 18 Netzvorlagen inklusive Industrie, DMZ, Mobile, Smart Home, School und Campus; beim Erstellen einer Lernaufgabe kann anschließend die Topologie gewählt werden.
- **CLI-Kompatibilität:** zusätzliche modellierte Windows-, Cisco-IOS-, Android- und iOS-Kommandos. Keine echten OS-Images oder Root-Kommandos auf dem Host.
- **Simulation:** Normale virtuelle ICMP-Heartbeats können im Hintergrund laufen, Sicherheitsvorfälle werden nie eigenständig gestartet. Eine Bedrohungsausbreitung findet höchstens während bewusst gestarteter Szenariotests statt.
- **Android-Zurück:** Speichern/Export, lokalen Entwurf sichern, zurückkehren oder App bewusst beenden.
- **Optik:** ruhigere Geräteauswahl und Bottom Sheets, eigener Smartphone-Glyph statt Laptop; unnötige lila Kontur im Kontextmenü entfernt.

## Kompatibilität / Sicherheit

Das ist eine lokale, didaktische Simulation: keine echten Linux-/IOS-Maschinen, keine externen Socket-Verbindungen, keine echten Scans oder Angriffe. Bestehende Weltdateien und die alte Codebasis werden nicht gelöscht. Die APK wird mit demselben Android-Debug-Zertifikat wie das veröffentlichte v0.6.0-APK signiert (Zertifikatsabgleich prüfen), damit Updates ohne Deinstallation möglich bleiben.

## Verifikation

- 12 bestehende Core-Tests erfolgreich.
- 18 bestehende v0.6-Netzwerk-Tests erfolgreich.
- Mobile Chromium-Oberflächentests: 18 Vorlagen, Subnetting, virtuelle Firewall-Regeln/CIDR, Paketsenden, OSI, Logs, Security, Smartphone und Back-Dialog.
