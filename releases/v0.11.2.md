# PacketLab v0.11.2 — OLED Material Polish

This release is a **visual refinement of the working Android app**, not a reskin or a replacement of its simulation logic.

## Visual changes

- Replaced the excessively large purple-bordered topology cards with a quiet, touch-friendly Android-style list.
- Grouped all 18 existing presets into **Grundformen** (7) and **Szenarien** (11), preserving names, actions, counts and size controls.
- Consolidated material colors into an OLED-black background, three distinct neutral surface levels, subtle dividers and restrained Veyra lavender only for selected items or primary actions.
- Refined font weight, readability, spacing, shape radii and icon treatment across sheets and dialogs.
- Applied the same visual language to device actions, the firewall editor, training list, import/save library, forms, the packet console and bottom navigation without removing features.
- Reduced unnecessary gradient/ring ornaments in Net@Lab V2 while retaining its chapter structure, interactive read-only demos and diagrams.
- Preserved the original Veyra wordmark, genuine purple branding, all 18 topologies, 90 handbook chapters, .pklab and .worklab file handling, haptics, and virtual OS support.

## No behavioral regressions

The app package ID and debug signing certificate remain unchanged. This build continues to use the original PacketLab graph and packet engines. No service, cable, firewall, training or device functionality was intentionally removed.

## Verification

- Mobile Chromium regression suite: original 40 functional checks plus additional UI composition, list density, Material surface, and handbook checks.
- Existing 12 core and 18 v0.6 network model tests.
- Android Gradle debug build and installation/start smoke test.
